# Sistema de Transacciones

Este repositorio contiene los 3 módulos que integran la solución:

1. **`api.gateway`**: API Gateway encargada de enrutar peticiones, orquestar la autenticación y aplicar validaciones de entrada.
2. **`api.transaccion`**: API de Persistencia responsable del procesamiento de transacciones y comunicación con la base de datos.
3. **`transacciones`**: Aplicación web frontend desarrollada en Angular.

---

## Requisitos Previos

* **Java**: 17 o superior
* **Maven**: 3.8+
* **Node.js**: 18+ y npm
* **Angular CLI**: `npm install -g @angular/cli`
